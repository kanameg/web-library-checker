# Product Overview

図書館蔵書チェッカーは、Amazon.co.jp や楽天ブックスの書籍ページを閲覧しながら、ユーザーが登録した図書館の蔵書・貸出状況をリアルタイムで確認できる Chrome 拡張機能です。

## Core Capabilities

- **書籍ページ検出**: Amazon.co.jp・楽天ブックスの書籍商品ページを自動検出し、ISBN を抽出
- **蔵書状況確認**: カーリル図書館 API（全国 7,400 館以上対応）を通じてリアルタイムに蔵書・貸出状況を取得
- **インライン表示**: 書籍ページ内に蔵書確認ウィジェットを挿入し、貸出可/貸出中/館内のみ等を色分け表示
- **図書館設定**: 都道府県・市区町村で図書館を検索し、最大 5 館まで登録・管理
- **予約ページ連携**: 図書館の予約ページへの直リンクを提供

## Target Use Cases

- 書籍購入前に図書館で借りられるか確認したいユーザー
- 複数の図書館の蔵書状況を一覧で比較したいユーザー
- Amazon・楽天での書籍閲覧体験をそのままに、図書館情報を手軽に参照したいユーザー

## Value Proposition

購入検討中の書籍ページを離れることなく、登録した図書館の蔵書状況を即座に確認できる点が価値。カーリル API によるポーリング・キャッシュ・リトライ処理をすべて内包し、ユーザーは API キーを設定するだけで利用開始できる。
