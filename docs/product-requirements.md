# プロダクト要求定義書 — 図書館蔵書チェッカー

| 項目 | 内容 |
|------|------|
| プロダクト名 | 図書館蔵書チェッカー |
| バージョン | 1.0.0 |
| 作成日 | 2026-04-06 |
| 対象プラットフォーム | Chrome 拡張機能（Manifest V3） |

---

## 1. 背景と目的

### 1.1 背景

書籍を購入する前に図書館で借りられるかどうか確認したいというニーズがある。しかし従来は、書籍ページを見ながら別タブで図書館のWebサイトやカーリル（https://calil.jp）を開き、ISBNを手動で入力して検索する必要があった。この作業は煩雑であり、特に購入検討中に複数の書籍をチェックするユーザーにとって大きな障壁となっていた。

### 1.2 目的

Amazon.co.jp・楽天ブックスの書籍ページを閲覧している最中に、その書籍が近くの図書館で借りられるかどうかをページを離れることなくリアルタイムで確認できるようにする。

---

## 2. ターゲットユーザー

| ユーザー層 | 説明 |
|-----------|------|
| 図書館利用者 | 書籍を購入する前に図書館での貸出状況を確認したいユーザー |
| 節約志向のユーザー | まず図書館で読んでから購入するか判断したいユーザー |
| 読書家 | 多数の書籍を検討するため、毎回手動検索する手間を省きたいユーザー |

**前提条件:** ユーザーはカーリルAPIキー（無料取得可）を持っているか、取得できる。

---

## 3. ユーザーの課題

| 課題 | 現状の問題 |
|------|----------|
| 蔵書確認の手間 | Amazon等で気になった本を図書館で検索するには、タブを切り替えてISBNを手動コピーする必要がある |
| 複数図書館の横断確認 | 自宅・勤務先・よく行く図書館など複数館を一度に確認できる手段がない |
| 貸出状況のリアルタイム性 | 図書館サイトで確認しても現在の貸出状況がわかりにくい場合がある |
| 予約への誘導 | 貸出中でも予約できる場合があるが、予約ページへのアクセスが面倒 |

---

## 4. プロダクト目標

### 4.1 主要ゴール

1. **ゼロ操作での蔵書確認**: 書籍ページを開いた時点で自動的に蔵書状況を表示する
2. **複数図書館の一括確認**: 最大5館の蔵書状況を1画面で確認できる
3. **予約へのスムーズな導線**: 貸出状況に応じて図書館の予約ページへ直接遷移できる

### 4.2 成功指標（参考）

- 対応ページを開いた際に蔵書確認ウィジェットが正常に表示される
- カーリルAPIの検索完了後、3秒以内に結果が表示される（通常時）
- Amazon・楽天ブックスの書籍ページでISBNが取得できない書籍率が5%未満

---

## 5. 主要な機能一覧

| # | 機能名 | 説明 |
|---|--------|------|
| 1 | 蔵書確認ウィジェットの自動表示 | Amazon・楽天ブックスの書籍ページを開くと、ページを離れることなく自動的に蔵書状況を確認できる |
| 2 | 複数図書館の一括蔵書確認 | 登録した最大5館の蔵書状況を1画面で同時に確認できる |
| 3 | 貸出状況の視覚的表示 | 貸出可・貸出中・蔵書なしなどのステータスを色分けで一目で確認できる |
| 4 | 図書館予約ページへのダイレクトリンク | 貸出中の書籍について、図書館の予約ページへ直接アクセスできる |
| 5 | ポップアップからの蔵書確認 | 拡張機能アイコンのポップアップからも現在ページの蔵書状況を確認できる |
| 6 | 図書館の検索・登録 | 都道府県・市区町村で図書館を検索し、最大5館まで登録できる |

## 6. 機能要件

### 6.1 書籍ページの自動検出

| 要件ID | 要件 | 優先度 |
|--------|------|--------|
| FR-01 | Amazon.co.jp の書籍詳細ページを自動検出する | Must |
| FR-02 | 楽天ブックスの書籍詳細ページを自動検出する | Must |
| FR-03 | 書籍ページ以外（検索結果・トップページなど）では何も表示しない | Must |

### 6.2 ISBN自動取得

| 要件ID | 要件 | 優先度 |
|--------|------|--------|
| FR-04 | Amazonの書籍詳細ページから書籍のISBNを自動取得する | Must |
| FR-05 | 楽天ブックスの書籍詳細ページから書籍のISBNを自動取得する | Must |
| FR-06 | ISBN取得に失敗した場合はウィジェットを表示しない（エラーを表示しない） | Must |

### 6.3 蔵書確認（ページ内ウィジェット）

| 要件ID | 要件 | 優先度 |
|--------|------|--------|
| FR-07 | 書籍ページ内の視認しやすい位置に蔵書確認ウィジェットを表示する | Must |
| FR-08 | 蔵書確認中は処理中であることを示し、完了後に結果を表示する | Must |
| FR-09 | 設定済みの図書館の蔵書状況をカーリルAPIを使って確認する | Must |
| FR-10 | 図書館ごとに蔵書状況（貸出可・貸出中・館内のみ・予約中・準備中・休館中・蔵書なし）を表示する | Must |
| FR-11 | 各館の貸出状態をアイコン色とラベルで区別して表示する | Must |
| FR-12 | APIレスポンスに予約URLが含まれる場合、予約ページへのリンクを表示する | Must |
| FR-13 | APIキーまたは図書館が未設定の場合、設定画面への誘導メッセージを表示する | Must |
| FR-14 | 同じページで同じ図書館への重複するAPI呼び出しを避ける | Should |

### 6.4 ポップアップ表示

| 要件ID | 要件 | 優先度 |
|--------|------|--------|
| FR-15 | 拡張機能アイコンクリックで現在ページの蔵書状況をポップアップ表示する | Must |
| FR-16 | 非対応ページでは「対応サイトではありません」を表示する | Must |
| FR-17 | 図書館ごとに代表ステータス（貸出可 > 貸出中 > その他の優先順）をリスト表示する | Must |
| FR-18 | APIレスポンスに予約URLが含まれる場合、各図書館の予約ページへのリンクをポップアップ内に表示する | Must |
| FR-19 | ポップアップから設定ページを開けるボタンを表示する | Must |

### 6.5 設定機能

| 要件ID | 要件 | 優先度 |
|--------|------|--------|
| FR-20 | カーリルAPIキーを入力・保存できる | Must |
| FR-21 | 都道府県・市区町村でカーリルAPIを使って図書館を検索できる | Must |
| FR-22 | 検索結果から最大5館を選択して登録・保存できる | Must |
| FR-23 | 設定をChromeプロファイル間で同期する | Must |

## 7. 非機能要件

### 7.1 パフォーマンス

| 要件ID | 要件 |
|--------|------|
| NFR-01 | ネットワークエラー時は自動的にリトライし、最終的に失敗した場合はエラーを表示する |
| NFR-02 | 検索に時間がかかりすぎた場合はタイムアウトエラーを表示する |
| NFR-03 | 複数図書館の蔵書確認を並列で実行し、一部の図書館で失敗しても他の図書館の結果を表示する |

### 7.2 セキュリティ

| 要件ID | 要件 |
|--------|------|
| NFR-04 | APIキーをページのコンテキストに露出させない |
| NFR-05 | 外部から取得したデータをページに表示する際、XSS攻撃を防ぐ |
| NFR-06 | ページに挿入するURLはhttp/httpsのみ許可する |

### 7.3 互換性・動作環境

| 要件ID | 要件 |
|--------|------|
| NFR-07 | Chrome拡張機能 Manifest V3 に準拠する |
| NFR-08 | 最小権限の原則に従い、必要最小限のブラウザ権限のみを要求する |
| NFR-09 | 対象サイトのページ構造変更に対して可能な限り動作を継続できる |

### 7.4 品質

| 要件ID | 要件 |
|--------|------|
| NFR-10 | 自動テストによりコード品質を継続的に担保する |
| NFR-11 | CIで自動テストを実施し、mainブランチへの変更を品質保護する |

## 8. 制約・前提条件

| 項目 | 内容 |
|------|------|
| 外部API依存 | カーリル図書館API（https://api.calil.jp）が利用可能であること |
| APIキー | ユーザーが自身のカーリルAPIキーを取得・設定する必要がある |
| 対応ブラウザ | Google Chrome（Manifest V3対応バージョン） |
| 対応サイト | Amazon.co.jp・楽天ブックスのみ（他サイトは対象外） |
| 図書館データ | カーリルAPIが提供する図書館情報（全国7,400館以上）に依存する |
| API利用制限 | カーリルAPIの利用制限（1,000リクエスト/時）に配慮し、セッションキャッシュで重複リクエストを防ぐ |

---

## 9. 対象外（スコープ外）

- Amazon.co.jp・楽天ブックス以外の書籍サイトへの対応
- Firefox・Edge など Chrome 以外のブラウザへの対応
- ユーザー間での設定共有・ソーシャル機能
- 蔵書確認履歴の保存・管理機能
- カーリルAPI以外の図書館APIへの対応
- 拡張機能側でのAPIキーの発行・管理
