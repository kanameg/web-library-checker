# 用語集 — 図書館蔵書チェッカー

---

## 1. ドメイン用語（図書館・書籍）

| 用語 | 定義 |
|------|------|
| 蔵書 | 図書館が所蔵している書籍・資料の総称 |
| 図書館システム | カーリルAPIにおける図書館の管理単位。1自治体や1運営法人が複数の館を持つ場合も、同一システムとして扱われる（例: 東京都立図書館システムに中央館・多摩館が属する） |
| 館（ブランチ） | 図書館システムの配下にある個別の建物・施設単位。カーリルAPIの `libkey` で館名をキーとして返される |
| 貸出状態 | カーリルAPIが返す各館の書籍の状態。以下の7種類が定義されている |
| 　貸出可 | 現在貸出できる状態 |
| 　貸出中 | 現在他の利用者に貸し出されている状態 |
| 　館内のみ | 館外への貸出は不可で、館内での閲覧のみ可能な状態 |
| 　予約中 | 予約が入っており順番待ちの状態 |
| 　準備中 | 新着・返却処理中などで貸出準備中の状態 |
| 　休館中 | 図書館が休館中の状態 |
| 　蔵書なし | その図書館に該当書籍の蔵書が存在しない状態 |
| ISBN | International Standard Book Number（国際標準図書番号）。書籍を一意に識別する番号。現行規格は13桁（ISBN-13）。旧規格は10桁（ISBN-10） |
| ISBN-13 | 978または979で始まる13桁の書籍識別番号。現在の国際標準 |
| ISBN-10 | 旧規格の10桁の書籍識別番号。先頭に978を付けてチェックデジットを再計算するとISBN-13に変換できる |
| ASIN | Amazon Standard Identification Number。Amazonが独自に付与する10桁の識別番号。数字のみのASINはISBN-10と一致する |
| チェックデジット | ISBNの末尾に付加される検証用数字。他の桁から計算され、入力誤りを検出するために使われる |
| 予約 | 貸出中の書籍を次に借りる権利を確保すること。各図書館の予約ページURL（`reserveurl`）から手続きできる |

## 2. ビジネス用語（サービス・API）

| 用語 | 定義 |
|------|------|
| カーリル | 全国7,400館以上の図書館蔵書を横断検索できるWebサービス（https://calil.jp）。本プロダクトはカーリルが提供するAPIを使用する |
| カーリルAPI | カーリルが提供するREST API。蔵書検索（`/check`）と図書館検索（`/library`）の2エンドポイントを持つ |
| APIキー | カーリルAPIを利用するためのアプリケーションキー（`appkey`）。カーリルの開発者登録ページから無料で取得できる |
| 蔵書確認 | 指定したISBNの書籍が、設定された図書館で借りられるかどうかをAPIで調べること |
| セッションキャッシュ | 同一タブのセッション内（ページリロードまで）でAPIレスポンスを保持する仕組み。同じ書籍・同じ図書館設定での重複リクエストを防ぐ |

## 3. UI/UX用語

| 用語 | 定義 |
|------|------|
| ウィジェット | 書籍ページのDOM内に挿入される蔵書確認UIブロック。`id="calil-library-checker"` の要素で識別される |
| ポップアップ | 拡張機能アイコンをクリックしたときに表示されるChrome拡張機能の小画面UI（`popup.html`） |
| 設定ページ | 拡張機能の設定を管理するページ（`options.html`）。APIキーの入力と図書館の登録・管理を行う |
| ステータスアイコン | 蔵書の貸出状態を示す色付き丸アイコン（CSSクラス `calil-status-icon`）。緑（貸出可）・黄（貸出中）・青（その他）・グレー（蔵書なし/休館中）・赤（エラー）の5色 |
| ローディング状態 | API呼び出し中にウィジェット内に表示されるスピナーとメッセージ（`calil-loading`） |
| 設定未完了状態 | APIキーまたは図書館が未設定の場合にウィジェット内に表示される設定誘導メッセージ（`calil-setup-message`） |
| クロスサイトリンク | ウィジェットのフッターに表示される、他方の書店ページへのリンク（Amazonページ→楽天ブックス、楽天ブックスページ→Amazon）（CSSクラス `calil-crosssite-link`） |
| 予約リンク | 図書館システムブロックのヘッダーまたはポップアップ内に表示される、図書館予約ページへのリンク（CSSクラス `calil-reserve-link`） |
| システムブロック | ウィジェット内で図書館システム（`systemid`）ごとに生成される表示単位（CSSクラス `calil-system-block`） |

## 4. 英語・日本語対応表

### カーリルAPIのフィールド名

| フィールド名（英語） | 日本語 | 備考 |
|---------------------|--------|------|
| `appkey` | APIキー | リクエストパラメータ |
| `isbn` | ISBN | リクエスト/レスポンス |
| `systemid` | 図書館システムID | 例: `Tokyo_Pref` |
| `session` | セッションID | ポーリング継続時に使用。APIサーバーが発行する識別子で、`continue=1` の間は再リクエストに付与して前回の検索結果を引き継ぐ |
| `continue` | 継続フラグ | `1` = 処理中（ポーリング継続）、`0` = 完了。`1` の間は `session` を付けて再リクエストする非同期処理方式 |
| `books` | 書籍データ | レスポンスのルートキー |
| `libkey` | 館別貸出状態 | `{"館名": "貸出状態"}` の形式 |
| `reserveurl` | 予約URL | 図書館の予約ページへのURL |
| `status` | 検索ステータス | `"OK"` または `"Error"` |
| `pref` | 都道府県 | 図書館検索パラメータ |
| `city` | 市区町村 | 図書館検索パラメータ（任意） |
| `formal_name` | 正式名称 | 図書館の公式名称。優先して表示名に使用 |
| `systemname` | システム名称 | `formal_name` が空の場合の代替表示名 |

### ストレージキー名

| キー名（英語） | 日本語 | 格納場所 |
|---------------|--------|---------|
| `calil_api_key` | カーリルAPIキー | `chrome.storage.sync` |
| `libraries` | 登録図書館リスト | `chrome.storage.sync` |

### メッセージタイプ名

| メッセージタイプ | 日本語 | 送受信方向 |
|----------------|--------|-----------|
| `CHECK_LIBRARY` | 蔵書確認 | コンテンツスクリプト/ポップアップ → サービスワーカー |
| `SEARCH_LIBRARIES` | 図書館検索 | 設定ページ → サービスワーカー |
| `GET_SETTINGS` | 設定取得 | コンテンツスクリプト/ポップアップ → サービスワーカー |
| `OPEN_OPTIONS` | 設定ページを開く | コンテンツスクリプト/ポップアップ → サービスワーカー |
| `GET_PAGE_INFO` | ページ情報取得 | ポップアップ → コンテンツスクリプト |

## 5. コード上の命名規則

### 定数（UPPER_SNAKE_CASE）

| 定数名 | 値 | 用途 |
|--------|-----|------|
| `CALIL_API_BASE` | `'https://api.calil.jp'` | カーリルAPIのベースURL |
| `POLL_INTERVAL_MS` | `2000` | ポーリング間隔（ミリ秒） |
| `MAX_POLL_COUNT` | `10` | ポーリング最大試行回数 |
| `MAX_RETRY_COUNT` | `3` | リトライ最大回数 |
| `MAX_LIBRARIES` | `5` | 登録可能な図書館の上限数 |

### CSSクラス名（`calil-` プレフィックス）

拡張機能が書籍ページに挿入するすべてのCSSクラスは `calil-` プレフィックスを付けて既存スタイルとの衝突を防ぐ。

| クラス名 | 役割 |
|---------|------|
| `calil-library-checker` | ウィジェット全体のルート要素（ID） |
| `calil-header` | ウィジェットヘッダー領域 |
| `calil-body` | ウィジェットコンテンツ領域 |
| `calil-footer` | ウィジェットフッター領域 |
| `calil-system-block` | 図書館システム単位のブロック |
| `calil-system-header` | 図書館システムブロックのヘッダー行 |
| `calil-system-name` | 図書館システム名のテキスト |
| `calil-branch-row` | 館（ブランチ）ごとの1行 |
| `calil-branch-name` | 館名のテキスト |
| `calil-branch-status` | 貸出状態のテキスト |
| `calil-status-icon` | 貸出状態を示す色付き丸アイコン |
| `calil-reserve-link` | 予約ページへのリンク |
| `calil-crosssite-link` | 他方の書店へのクロスサイトリンク |
| `calil-loading` | ローディング状態のコンテナ |
| `calil-spinner` | スピナーアニメーション要素 |
| `calil-error` | エラー状態の表示 |
| `calil-no-stock` | 蔵書なし状態の表示 |
| `calil-setup-message` | 設定未完了時の誘導メッセージ |

### ステータスCSSクラス名（貸出状態の色分け）

| クラス名 | 対応する貸出状態 | 表示色 |
|---------|----------------|--------|
| `available` | 貸出可 | 緑（`#2e7d32`） |
| `on-loan` | 貸出中 | 黄（`#f57f17`） |
| `other` | 館内のみ・予約中・準備中・その他 | 青（`#1565c0`） |
| `none` | 蔵書なし・休館中 | グレー（`#9e9e9e`） |
| `error` | APIエラー | 赤（`#c62828`） |

### セッションキャッシュキー形式

```
calil_{ISBN-13}_{systemid1,systemid2,...}
```

- `systemid` はアルファベット順でソートしてカンマ区切り
- 例: `calil_9784873117386_Osaka_Pref,Tokyo_Pref`
